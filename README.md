# Budget, Cost, Profitability & Variance Analysis

## Overview

This project presents a practical **management accounting and financial analysis model** developed in Microsoft Excel. The analysis focuses on budgeting, cost management, profitability, Cost-Volume-Profit (CVP) analysis, Activity-Based Costing (ABC), flexible budgeting, and variance analysis.

The project demonstrates how management accounting techniques can be used to evaluate cost behavior, product profitability, operational performance, and differences between budgeted and actual results.

## Project Objectives

- Analyze budgeted and actual financial performance
- Classify costs according to their behavior and nature
- Evaluate contribution margin and profitability
- Perform Cost-Volume-Profit (CVP) analysis
- Calculate break-even sales and units
- Determine sales required to achieve a target profit
- Analyze operating leverage and margin of safety
- Apply Activity-Based Costing (ABC)
- Allocate overhead costs to products using activity cost drivers
- Prepare static and flexible budgets
- Calculate and interpret budget variances
- Evaluate the financial impact of operational variances
- Identify key areas of cost and profitability performance

## Key Findings

The analysis demonstrates how changes in sales volume, cost structure, overhead allocation, and operational efficiency can affect profitability.

The CVP analysis identifies the level of sales required to cover fixed and variable costs and evaluates the additional sales required to achieve a target operating profit.

The ABC analysis demonstrates how allocating overhead based on activity cost drivers can produce different product-level cost results compared with traditional allocation methods.

The flexible budget analysis separates changes caused by activity levels from differences resulting from operational performance.

The variance analysis identifies the individual cost and revenue drivers contributing to differences between budgeted and actual operating results.

Together, these analyses provide a structured view of cost behavior, profitability, budgeting performance, and operational variance management.
